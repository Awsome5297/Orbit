# 草图编辑器重设计

## 目标

把媒体创作里的草图从“白底画笔弹窗”换成完整的全屏画板：固定白色画纸、可选画纸比例、画笔与笔型、文字、选择与变换、橡皮、调色板与自定义颜色、可撤销的擦除与清空。参考 rikkahub 的界面结构与操作方式，按本项目的 Compose 与 Material 组件独立实现，不复制 AGPL 源码。

## 原状况

- `MediaSketchDialog` 只有一个全屏 `Dialog`，顶栏是文字按钮，画笔粗细靠数字输入框。
- 橡皮分“笔画擦”和“区域擦”，擦除直接改笔画列表；清空不可撤销。
- 没有文字、选择、画纸比例、自定义颜色，画纸比例始终跟随可用区域。
- 导出固定为画布像素尺寸，带底图时直接按屏幕布局出图。

## 新结构

```text
app/src/main/java/com/ai/assistance/operit/ui/features/media/sketch/
	SketchModel.kt		步骤、笔型、放置、路径与命中测试
	SketchState.kt		画纸、步骤栈、撤销重做、选择、文字、擦除
	SketchCanvas.kt		画布绘制、指针手势、选框与选中框
	SketchToolbar.kt	粗细档位、笔型菜单、工具、颜色与调色面板
	SketchDialog.kt		全屏窗口、顶栏、放弃确认与文字输入
	SketchImage.kt		底图读取与 PNG 导出
```

## 关键设计

- 画纸坐标以画纸中心为原点，落笔后画纸尺寸固定；屏幕与导出只是对同一套坐标做缩放。
- 一次操作是一步：笔画、文字、擦除、变换、清空。撤销重做直接增删步骤。
- 橡皮作为带 `BlendMode.Clear` 的步骤画在笔画图层里，只擦笔画，不影响画纸和底图，并且可以撤销。
- 选择与移动、缩放记录为变换步骤，选中框只画在屏幕上，不进入导出图片。
- 空白画纸按 1536 长边导出；带底图时按底图分辨率导出。统一输出 PNG。
- 空画纸比例默认跟随生成参数里的分辨率，也可以在画纸菜单里改为自动或预设比例。
