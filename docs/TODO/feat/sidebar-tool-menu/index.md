# 侧栏工具菜单与权限迁移

## 目标

移除侧栏顶部的“权限”和“工作流”快捷卡片，让角色区和历史区整体上移；底部“包管理”改为“工具菜单”，点击向上展开包含“包管理”和“工作流”的下拉菜单；权限入口集中到设置页。

## 范围

- `ChatSidebarContent`：删除顶部快捷卡片、`permissionBadgeText` 和 `showNavigationShortcuts` 参数。
- `DrawerContent`：底部按钮改为工具菜单，菜单项导航到包管理和工作流。
- `SettingsScreen`：新增“权限与安全”分组，将工具权限入口从“数据和权限”移到该分组。
- `ChatScreenShell` 与主题工作室预览：同步移除旧参数。
- 不改变包管理页、工作流页和权限页本身的业务逻辑。

## 实现清单

- [x] 删除侧栏顶部权限/工作流快捷卡片及相关状态计算。
- [x] 底部“包管理”改为“工具菜单”，锚定展开两项菜单。
- [x] 设置页新增“权限与安全”分组并迁移权限入口。
- [x] 更新所有调用方参数。
- [x] 静态检查旧引用和布局结构。

## 验证方式

- 侧栏顶部不再显示权限/工作流卡片，角色行紧跟标题。
- 底部工具菜单可展开“包管理”和“工作流”，点击外部关闭。
- 设置页首屏可见“权限与安全”分组和权限入口。
- 按项目规则不在本地执行编译或测试，提交后由 CI 验证。
