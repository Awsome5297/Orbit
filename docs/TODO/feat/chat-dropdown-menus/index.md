# 聊天页下拉菜单改造

## 目标

把会话操作菜单和角色选择器从居中弹窗/整屏覆盖改为锚定触发控件的下拉菜单，保留原有操作与数据逻辑。

## 范围

- 会话操作：编辑标题、总结标题、归档/取消归档、置顶/取消置顶、锁定/解锁、删除。
- 角色选择：角色组与角色卡列表、排序、编辑入口、当前选中状态。
- 不改动编辑标题、删除确认等需要输入或二次确认的对话框。

## 实现清单

- [x] `HistoryActionsDialog` 改为可复用的下拉菜单内容，删除危险项使用错误色。
- [x] `FolderTreeList` 在每行 `...` 按钮处锚定下拉菜单，避免面板级居中弹窗。
- [x] `CharacterSelectorPanel` 拆成内容组件，由侧栏角色行锚定下拉菜单承载。
- [x] 共享菜单定位器在右侧锚点改为右对齐，避免菜单跳到屏幕另一侧。
- [x] 更新 `ChatSidebarContent` 的调用与状态传递。
- [x] 静态检查旧弹窗调用和未使用导入。

## 验证方式

- 检查会话行 `...` 菜单出现在按钮下方或上方，点击外部/返回键可关闭。
- 检查角色选择菜单出现在角色行下方，角色多时菜单内部可滚动。
- 按项目规则不在本地执行编译或测试，提交后由 CI 验证。
