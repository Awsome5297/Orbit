# 草图编辑器

媒体创作的草图是一个全屏画板，用来给图片和视频生成画面补一张参考图。入口在参考素材面板的“草图”，确认后得到一张 PNG，作为参考素材加入当前草稿。

## 坐标与画纸

画纸坐标以画纸中心为原点，单位与首次布局时的屏幕像素相同。落笔之后画纸尺寸固定，屏幕旋转或改变可用区域只缩放显示，不改变已有笔画的位置。

- 空白画纸按所选比例在可用区域里放到最大。
- 垫入底图后，画纸比例跟随底图。
- 屏幕绘制与导出共用同一套画纸坐标，两者的差别只有缩放比例。
- 白色画纸固定为白色，不跟随应用的深浅色主题，导出的图片在不同设备上一致。

## 步骤模型

画板上的每次操作都是一步，按顺序保存在步骤列表里：

- 笔画：一组带宽度的采样点，记录笔型、颜色与基础粗细。
- 文字：静态排版结果，记录位置、字号、颜色与换行宽度。
- 擦除：一条擦除路径与宽度，绘制时使用清除混合模式。
- 变换：一次移动或缩放，记录作用的笔画和文字以及放置参数。
- 清空：画纸重置，本身也可以撤销。

撤销把最后一步移到重做栈，重做再移回来。清空之前的步骤仍留在列表里，但绘制时从最后一次清空之后开始。

## 绘制

绘制顺序是白色画纸、底图、笔画图层、当前笔画。笔画和文字都画在同一个离屏图层里，擦除步骤在这个图层上用 `BlendMode.Clear` 清出透明区域，因此擦除只影响笔画，不会擦掉底图和画纸。

选中框和选框在笔画图层之外绘制，只在屏幕上出现，导出时跳过。

## 工具

- 画笔：六种笔型，钢笔、马克笔、平头笔、毛笔、荧光笔和虚线。钢笔、平头笔和毛笔按采样点宽度生成轮廓填充；马克笔、荧光笔和虚线使用描边，荧光笔带透明度和加宽。
- 文字：点击画纸后弹窗输入，回车确认后按当前颜色和粗细落字，超出画纸右半边自动换行。
- 选择：点一下选中最上面的笔画或文字，拖动选中范围是移动，拖四角是缩放，在空白处拖动是框选。
- 橡皮：按当前粗细的四倍擦除，落笔和拖动都立即生效。

## 导出

- 空白画纸按 1536 长边导出，与屏幕分辨率无关。
- 带底图时按底图宽度导出，笔画和文字随画纸缩放。
- 输出 PNG，写入应用缓存目录后交给媒体创作页作为参考素材。

## 接入

`MediaSketchDialog` 保持原有的 `onDismiss` 与 `onSave(File)` 回调。媒体创作页把当前分辨率换算成初始画纸比例，未设置分辨率时使用自动比例。
