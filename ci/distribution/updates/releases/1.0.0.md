# 1.0.0

本版把发行版本线重置为 `1.0.0`，versionCode 重置为 1，作为后续 `1.0.0+n` 增量更新的完整包基线。包名和固定签名不变。

## 媒体创作

- 媒体创作工作台支持参考图、首帧和尾帧素材，新增草图编辑器、批量保存和最近生成选择。
- 草图编辑器提供全屏画板、六种笔型、文字与选择工具、可撤销的擦除和清空，以及预设和 HSV 自定义颜色。
- 画纸支持自动和常用比例，也可以垫入图片描画；草图比例跟随媒体生成分辨率。

## 后台生成

- 媒体生成任务改为应用级执行，退出创作页或切后台后继续运行。
- 生成期间使用前台服务保活，通知栏显示生成状态，结束后自动移除。
- 进程被强制停止后，下次进入会把遗留记录标记为“生成已中断”。

## 安装与更新

- 这是新的完整包基线，没有从旧版本线生成的增量包。
- 已安装 `1.12.2+24` 的设备需要先卸载旧包，再安装 `1.0.0`；Android 不允许把 versionCode 从 80 降到 1。
- 安装 `1.0.0` 后，后续 `1.0.0+1`、`1.0.0+2` 等版本使用增量包更新，versionCode 从 2 继续递增。
- 旧版本线 `v1.12.2+23`、`v1.12.2+24` 仍按版本名高于 `1.0.0`；开启 Beta 的 `1.0.0` 客户端可能把它们识别为更新。正式公开前需要把旧版本标记为 prerelease，或关闭 Beta 检查。
- 本次创建 `v1.0.0` 完整包基线 Release，不含增量包。
